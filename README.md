# Sistema-contable-2


Este proyecto es una aplicación web desarrollada para gestionar un catálogo interactivo de libros y discos de música. Permite organizar, visualizar y registrar distintas obras y publicaciones de manera sencilla mediante una interfaz clara y funcional.

---

## ¿De qué trata el proyecto?

Es una plataforma pensada para la gestión de medios digitales. La aplicación permite integrar en un mismo lugar tanto colecciones literarias como catálogos musicales, facilitando la navegación entre diferentes tipos de contenido dentro de la misma estructura web.
